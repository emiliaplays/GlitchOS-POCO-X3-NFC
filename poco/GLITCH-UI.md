Applied:

- Glitch UI branding, 24-hour clock, matching rounded app-icon frames and the existing
  app search, favorites and native media controller.

  are still provided by MIUI. Launcher icon frames do not replace all system icons.

## Successful local installation via factory Theme Manager (2026-11-07)

The factory APK /system/app/MIUIThemeManagerGlobal/MIUIThemeManagerGlobal.apk
(version 2.1.0.8-global) contains the exported ApplyThemeForScreenshot alias.
The installed update 2.15.9.5-global does not. Both APK signing certificates have
SHA-256 c9009d01ebf9f5d0302bc71b2fe9aa9a47a432bba17308a3111b75d7b2149025.

Backed up 607 external Theme Manager files (11,226,467 bytes) to
local/theme-factory-test/external-data. Private internal data was not accessible
without root and is not claimed to be backed up. Original update and factory APK
are saved in local/glitchui-1.1-baseline/.

Used Android's cmd package uninstall-system-updates com.android.thememanager to
return only this app to the factory version. Pushed the MTZ to
/sdcard/MIUI/theme/MIUIThemeToolGenerated.mtz and launched:

adb shell am start -W -n com.android.thememanager/com.android.thememanager.ApplyThemeForScreenshot --es theme_file_path /sdcard/MIUI/theme/MIUIThemeToolGenerated.mtz --es api_called_from ThemeEditor_21.8.16

This factory implementation always opens Android's file picker. Searched for
GlitchUI and selected Download/GlitchUI-Poco.mtz. The native apply progress ran.
/data/system/theme/description.xml subsequently contained Glitch UI POCO 1.1.0;
new icons and wallpapers were present in the active system theme directory.
The mint/navy icon wrapping was visible in Android DocumentsUI and real Recents,
independently of the Glitch launcher. Reading the active icon ZIP was denied;
no bypass was attempted.

Reinstalled the saved signed 2.15.9.5-global update with adb install -r. The active
Glitch theme description persisted and the themed Recents icon was verified after
the update. HOME still resolves to com.glitchos.mobile/.MainActivity, night mode
is yes, recents suggestions remain 0, Settings opens, and SystemUI still binds
to POCO's TouchInteractionService. Left the device at Glitch Home.

This supersedes the earlier finding that local application was unavailable with
the installed update alone. No root, signature verification changes, patched APK,
bootloader changes or global security changes were required. Persistence over a
reboot or a later licensing/server refresh has not been verified. This is a local
development/test application, not a published store listing. The MTZ contains
wallpapers and icons only; it does not supply custom Settings/SystemUI modules.
For rollback, apply the original POCO theme through Themes > My account > Themes.
