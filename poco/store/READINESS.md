## Theme store

The existing GlitchUI-Poco.mtz is a private device-generated prototype, not a
review-ready store package. It embeds icons read from installed third-party apps.
Do not claim those icons as original artwork or submit an invented copyright
certificate. Build a separate store edition with original, identifiable icons,
the required app coverage and animated Weather/Clock/Calendar adaptations.
The current package does not include these adaptations or custom system modules.

Use the original wallpaper drawing source (GlitchTheme.java) as evidence for that
artwork only. The copied source file also documents the prototype's icon-export
implementation; it is not evidence of ownership of the exported app icons.
Do not advertise the native launcher, media controls or horizontal Recents as
features installed by the MTZ. They are separate app/system configuration.

Before submission: complete an actual Designer account, inspect the live upload
form, prepare required previews and original-art evidence, validate the package
on supported devices, and submit for Xiaomi's review. Publication is conditional
on review; a store submission cannot guarantee an immediate installation route.
